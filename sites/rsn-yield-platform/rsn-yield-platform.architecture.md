## 1. Purpose

Sanitized portfolio re-implementation of an internal yield-management chain for a Regional Sports Network. It mirrors the production Power Query → Pivot Table chain that runs against Wide Orbit SSRS exports for an MLB-team RSN (~170 televised games/season, ~$30–60MM annual ad revenue), but every figure displayed is **synthetic and deterministic**. The build pipeline (`prebuild`) generates synthetic source files, runs the ETL, and gates the build on 53 property-based contracts and 24 distributional metrics before `next build`. The sub-project lives under `sites/rsn-yield-platform/` in the host portfolio repo but is excluded from the host TypeScript project (`tsconfig.json` exclude `["node_modules", "sites"]` at the host root) and is deployed as its own Vercel project at `rsn-yield.zachsparkman.com` (per the link in `src/app/portfolio/page.tsx:108–110` of the host).
